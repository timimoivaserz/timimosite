# Лаборатория ТИМиМО — статический сайт

Сайт полностью статический: **никаких сборок, Node.js, интернета и баз данных не нужно**.
Работает одинаково хорошо через XAMPP и при простом открытии файла в браузере.

## Как запустить через XAMPP (самый простой способ)

1. Скопируйте все файлы из этой папки в `C:\xampp\htdocs\lab\`
   (нужно, чтобы получилось: `htdocs\lab\index.html`, `htdocs\lab\assets\...`, `htdocs\lab\styles.css` и т.д.)
2. Запустите Apache в панели XAMPP (кнопка Start).
3. Откройте в браузере: **http://localhost/lab/**

Всё — сайт открывается сразу, без установки чего-либо.

> Важно: копируйте именно СОДЕРЖИМОЕ папки (index.html, styles.css, main.js, assets),
> а не саму папку внутрь себя — иначе index.html окажется в подпапке и по адресу
> http://localhost/lab/ будет список файлов.

## Ещё проще — без XAMPP

Можно просто дважды кликнуть `index.html` — сайт откроется напрямую (file://):
все стили, скрипты, картинки и шрифты локальные, интернет не требуется.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Страница сайта со всеми секциями (О лаборатории, Направления, Публикации, Команда, Контакты). Навигация — якорные ссылки с плавной прокруткой. |
| `styles.css` | Скомпилированный Tailwind CSS v4, включая локальные @font-face для Montserrat. |
| `main.js` | Ванильный JS: тёмная тема + мобильное меню. Работает и на file:// (localStorage защищён try/catch). |
| `assets/logo.svg`, `assets/b0553.png` | Логотип и фоновая сетка. |
| `assets/fonts/*.ttf` | Шрифты Montserrat (Regular/Medium/SemiBold/Bold) — сайт полностью офлайн. |
| `.htaccess` | Отключает агрессивное кэширование Apache (обновления сайта видны сразу). |

## Возможные проблемы и решения

- **Показывает список файлов вместо сайта** → `index.html` лежит не в корне папки сайта; положите его рядом с `assets/`, `styles.css`, `main.js`.
- **Apache не запускается (порт 80 занят)** → в панели XAMPP: Config → Apache → httpd.conf, замените `Listen 80` на `Listen 8080` и открывайте http://localhost:8080/lab/.
- **После правок сайт не обновился** → Ctrl+F5 (жёсткая перезагрузка).
- **Тема не запоминается при открытии через file:// в Firefox** → это ограничение браузера; через XAMPP (http://localhost) работает всегда.

## Для разработчиков

Исходники React-проекта и собранной статики — в репозитории (`src/`, `static/`).
Обновление стилей после правок `src/index.css`:

```bash
npx @tailwindcss/cli@4 -i src/index.css -o static/styles.css
```

Автотесты логики (тёмная тема, меню, якоря): `node test.cjs` (нужен jsdom).
