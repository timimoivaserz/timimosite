# Статическая версия сайта Лаборатории ТИМиМО

Папка `static/` — полностью статическая (без React/Vite) версия сайта из корня репозитория.
Вся логика и оформление сохранены.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Одностраничная версия сайта (все секции: О лаборатории, Направления, Публикации, Как мы работаем, Команда, CTA, Footer). Навигация — якорные ссылки с плавной прокруткой. |
| `styles.css` | Скомпилированный Tailwind CSS v4 (включая `@theme`, кастомные цвета/шрифты и `@font-face` для Montserrat из `public/fonts`). Генерируется из `src/index.css`. |
| `main.js` | Ванильный JS без зависимостей: тёмная тема + мобильное меню. |
| `assets/logo.svg`, `assets/b0553.png` | Скопированы из `public/assets`. |

## Сохранённая логика

- **Тёмная тема** (аналог хука `useDarkMode`): начальное значение берётся из `localStorage("theme")`, иначе — из системной темы (`prefers-color-scheme`); переключение добавляет/снимает класс `dark` у `<html>` и сохраняет выбор; иконки луны/солнца переключаются; подписка на изменение системной темы.
- **Мобильное меню**: бургер открывает/закрывает выпадающее меню (меню скрыто в desktop), клик по ссылке закрывает меню, анимация бургера в крестик.
- **Оформление 1:1**: sticky-хедер без blur, hero с фоновой сеткой (opacity-0, как в оригинале), карточки статистики с абсолютно позиционированными «+», лента публикаций с `divide-y`, градиентные блоки команды/CTA, тёмные варианты всех секций.

## Сборка / обновление

```bash
npx @tailwindcss/cli@4 -i src/index.css -o static/styles.css
```

(В `src/index.css` добавлены директивы `@source "./static/main.js"` и `@source inline(...)` — они гарантируют попадание в CSS классов, которые навешиваются из JS.)

## Запуск

Достаточно открыть `static/index.html` в браузере или раздать папку:

```bash
python3 -m http.server --directory static 8000
```
